# customer-churn-analysis

# Customer Churn Prediction

카드 고객의 이탈 여부와 향후 LTV를 예측한 데이터 분석 프로젝트입니다.

## 프로젝트 목표
고객 데이터를 활용하여 이탈 가능성이 높은 고객을 예측하고,
고객 유지 전략에 활용할 수 있는 모델을 구축하는 것을 목표로 했습니다.

## 담당 업무
- Raw data 전처리(train_final이 전처리 데이터)
- 왜도 보정
- 이상치 처리
- 파생변수 생성
- 모델 성능 비교 및 개선

## 사용 기술
- Python
- pandas
- scikit-learn

## 분석 과정
1. 데이터 탐색
2. 결측치 및 이상치 처리
3. 변수 변환 및 파생변수 생성
4. 모델 학습
5. 성능 비교
6. 결과 해석
Customer churn prediction and LTV analysis
